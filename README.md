# BSc Thesis Website: World Models

Website for our Cairo University BSc thesis on world models (sample efficiency and physics intuition, evaluated on IntPhys2).

Built with React, Vite, Ant Design and Framer Motion. Content lives in `src/data`.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build
npm run lint
```

Deployed to GitHub Pages via `.github/workflows/deploy.yml`.
